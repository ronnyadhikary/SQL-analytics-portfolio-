# SQL Analytics Portfolio

This repository contains SQL projects demonstrating practical business data analysis using MySQL.


## Project 1: Sales Performance Analysis
- Calculated total sales, profit, and quantity using aggregate functions.
- Analyzed monthly sales and profit trends using SQL date functions.
- Identified loss-making categories using HAVING.
- Ranked top-performing products using ORDER BY and LIMIT.
- Tools: MySQL (DB Fiddle)


## Project 2: Customer & Sales Analysis (JOIN Project)
- Combined customer and order data using SQL JOINs.
- Analyzed monthly sales trends by customer segment.
- Ranked top customers based on sales performance.
- Identified loss-making customers using HAVING for business insights.
- Tools: MySQL (DB Fiddle)


### Skills Demonstrated
- SQL aggregation and filtering
- JOINs and multi table analysis
- Date based trend analysis
- Business focused data insights
